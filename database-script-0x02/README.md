## **Sample Data Overview**

- **Users:** 4 users including guests, host, and admin
- **Properties:** 2 properties owned by the host
- **Bookings:** 2 bookings for different users and properties
- **Payments:** Payments linked to each booking
- **Reviews:** User feedback for booked properties
- **Messages:** Sample communication between users

---

## **Purpose**

The sample data is designed to reflect **real-world Airbnb usage**, including multiple users, bookings, payments, and reviews.  
It allows testing queries, joins, and application features without requiring live data.
